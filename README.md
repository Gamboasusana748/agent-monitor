## 👋 Welcome to agent-monitor

agent-monitor is a simple yet powerful tool that lets you **see what your AI subagents are doing**. If you use Codex or Claude Code, you know how hard it can be to keep track of multiple agents working on tasks. agent-monitor solves this by showing you a clear, visual picture of every agent's activity.

Think of it like a **dashboard for your AI helpers**. You can watch their progress, see exactly what they're working on, understand how much they cost, and spot any issues—all in one place.

## 🎯 What Does agent-monitor Do?

agent-monitor takes the guesswork out of managing AI agents. Here's what you get:

### 👁️ Visualize Your Agents
Watch your Codex and Claude Code subagents in real time. You'll see:
- Which agents are active right now
- What each agent is currently working on
- The history of actions each agent has taken
- How agents connect and pass work to each other

### 🔍 Advanced Traces View
Dive deep into every single step your agents take. This isn't just a simple log—it's a full trace that shows you:
- The exact order of operations
- Which prompts were sent
- What responses came back
- Where errors occurred
- How long each step took

### 💰 Tokens Breakdown
Tokens are the "fuel" that AI agents use. agent-monitor breaks down your token usage so you can see:
- How many tokens each agent consumed
- Which tasks used the most tokens
- Token usage trends over time
- Where you might be wasting resources

### 📈 Cost Usage Tracking
Money matters. agent-monitor shows you exactly what your AI usage costs:
- Daily, weekly, and monthly cost totals
- Cost per agent and per task
- Comparison between Codex and Claude Code expenses
- Budget alerts so you never overspend

## 🔧 Troubleshooting

### Problem: The app won't install
- Make sure you have Windows 10 or newer
- Temporarily disable your antivirus during installation
- Right-click the installer and select "Run as administrator"

### Problem: I can't connect my AI account
- Check your internet connection
- Make sure you're logged into your AI tool's account
- Restart agent-monitor and try again

### Problem: Charts aren't showing data
- Give the app a few minutes to collect data
- Check that your agents have been active
- Try refreshing the view

### Problem: The app won't open
- Restart your computer
- Reinstall agent-monitor
- Contact support for help
